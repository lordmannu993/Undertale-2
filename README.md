# Undertale-2

A browser-based Undertale-inspired fan prototype built with plain HTML/CSS/JavaScript.

## Run

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- Arrow keys: move (overworld and soul movement)
- `Z`: interact / confirm
- `X`: back / leave battle after `MERCY` or victory

## Included demo features

- Overworld exploration between connected rooms
- NPC interaction dialog with proximity check
- Triggered battle scene with Undertale-style menu
- Enemy attack phase where you dodge projectiles with a heart
- Basic HP, victory, mercy, and defeat states

This is still a compact fan prototype (not a one-to-one release of the original game).
