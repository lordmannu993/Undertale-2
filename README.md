# Undertale-2

A small browser-based Undertale recreation prototype built with plain HTML/CSS/JavaScript.

## Run

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included demo features

- Overworld exploration between simple connected rooms
- NPC interaction dialog
- Triggered battle scene with Undertale-style menu
- Enemy attack phase where you dodge projectiles with a heart
- Basic HP, victory, mercy, and defeat states

This is a compact prototype and not a full one-to-one release of the original game.
